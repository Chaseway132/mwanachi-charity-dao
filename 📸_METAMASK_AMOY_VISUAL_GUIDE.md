## 🆘 If Something Goes Wrong

### Problem: "Network refused to be created"
**Solution:**
1. Delete the network (click ⋮ next to it)
2. Try adding again
3. Make sure RPC URL is exactly: `https://rpc-amoy.polygon.technology`
4. Make sure Chain ID is exactly: `80002`

### Problem: Still shows Ganache
**Solution:**
1. Make sure you clicked "Save"
2. MetaMask should automatically switch to new network
3. If not, click the network dropdown and select "Polygon Amoy"

### Problem: Can't find "Add network" button
**Solution:**
1. Make sure you're on the network selection screen
2. Scroll down if needed
3. Look for "➕ Add network" button
